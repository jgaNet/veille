# Repères — flux ecologie

Dernières valeurs officielles d'un petit nombre d'indicateurs de référence.
Voir `ecologie/CONSIGNES.md`, § 8.

**Règle absolue :** une valeur n'est inscrite ici que si le passage l'a lue
lui-même dans la source primaire citée, le jour indiqué. Une ligne vide vaut
mieux qu'une valeur de mémoire. Toujours préciser le jeu de données, la
période et la référence (par exemple 1850-1900).

Format d'une ligne du tableau :
`| indicateur | valeur et unité | période | jeu de données / organisme | lien | relevé le AAAA-MM-JJ |`
